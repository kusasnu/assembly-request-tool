# 자료요구서 문항 분해 스킬

이 스킬은 `원문/` 폴더의 자료요구서 PDF를 읽어 `data/문항목록.csv`를 만드는 `split.py`를 작성하거나 수정할 때 쓴다. 목표는 사용자가 교체한 현재 `data/문항목록.csv`와 같은 형식과 내용이 다시 나오도록 `split.py`를 남기는 것이다.

## 먼저 읽을 것

1. `PROGRESS.md`
2. `CONTEXT.md`
3. `처리지침.md` 제2장 접수
4. 현재 `data/문항목록.csv`
5. 기존 `split.py`가 있으면 그 파일

`99_완성본_잠금` 폴더는 열지 않는다.

## 준비

- `pypdf`만 사용한다.
- 먼저 `import pypdf` 또는 `from pypdf import PdfReader`가 되는지 확인한다.
- `pypdf`가 없으면 설치하지 말고 `pip install pypdf` 명령을 보여 준 뒤 사용자 허락을 받는다.

## 입력과 출력

- 입력 PDF: `원문/*.pdf`
- 생성 코드: 루트의 `split.py` 하나
- 출력 CSV: `data/문항목록.csv`
- CSV 인코딩: `utf-8-sig`
- CSV 열 순서: `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`

원문 PDF는 고치지 않는다. 사용자가 명시하지 않으면 `data/`의 다른 파일도 고치지 않는다.

## 처리 규칙

1. 첫 줄 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 뽑는다.
2. `수신: ... 제출기한: 2026. 10. 12.(월) 18:00까지` 줄에서 제출기한을 `YYYY-MM-DD`로 바꾼다.
3. `수신:`, `담당 보좌관:`, `끝.` 줄은 문항에 넣지 않는다. 이름과 연락처는 저장하지 않는다.
4. 줄 맨 앞이 `숫자.`이면 새 문항이다.
5. `가.`, `나.` 같은 줄은 앞 문항의 세부항목이다.
6. `※`로 시작하는 줄은 앞 문항의 비고다. 현재 문항목록 기준으로 `※` 기호는 저장하지 않고 뒤의 내용만 저장한다.
7. 그 밖의 줄은 바로 앞 항목에 이어 붙인다.

## 현재 문항목록 기준

- 문항번호는 CSV에 문자열로 쓴다.
- 세부항목이 여러 줄이면 ` / `로 이어 저장한다.
- 비고가 여러 줄이면 ` / `로 이어 저장한다.
- PDF 파일명에 `_25문항.pdf`처럼 문항 수가 있으면 그 수를 기준으로 추출 결과를 대조한다.

## 확인 기준

`split.py` 작성 또는 수정 후 실행해서 다음을 확인한다.

- 파일별 `파일명의 문항 수 | 뽑은 문항 수 | 마지막 번호 | 번호 연속 | 일치(O/X)` 표를 출력한다.
- 전체 CSV 열이 지정한 8개 열과 같은지 확인한다.
- 전체 문항 수와 파일별 문항 수가 현재 `data/문항목록.csv` 기준과 같은지 확인한다.
- `수신:`, `담당 보좌관:`, `연락처`, `끝.`이 CSV 값에 들어가지 않았는지 확인한다.
- 세부항목 또는 비고가 있는 문항 3개를 원문 PDF에서 뽑은 줄과 CSV 저장 내용으로 나란히 보여 준다.
- 임시로 재추출한 결과와 현재 `data/문항목록.csv`를 행 단위로 비교한다.

일치가 X이거나 기준 CSV와 다른 행이 있으면 원인을 찾고 `split.py`를 고친 뒤 다시 실행한다. 사용자가 새 결과로 교체하라고 명시한 경우에만 `data/문항목록.csv`를 덮어쓴다.

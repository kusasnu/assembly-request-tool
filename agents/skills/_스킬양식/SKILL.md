# 스킬 제목

## 언제 쓰는지

- 이 스킬을 사용할 상황을 적는다.
- 비슷하지만 이 스킬을 쓰지 않을 상황이 있으면 함께 적는다.

## 순서

1. 먼저 읽거나 확인할 자료를 적는다.
2. 작업 대상을 확인하는 방법을 적는다.
3. 사용자가 선택해야 하는 부분이 있으면 먼저 제안하고 기다린다.
4. 사용자가 고른 내용만 실제 파일에 반영한다.
5. 결과를 검증하고 `PROGRESS.md`에 기록한다.

## 끝나는 조건

- 만들어야 할 파일이나 바뀐 파일이 있는지 확인한다.
- 검증 결과가 기준을 만족하는지 확인한다.
- 남은 일과 막힌 점이 있으면 기록한다.

## 하지 말 것

- 사용자가 고르지 않은 내용은 반영하지 않는다.
- 원본 자료를 직접 고치지 말아야 하는 경우에는 사본만 만든다.
- 근거 자료에 없는 값이나 조직도에 없는 부서명을 만들지 않는다.
- 검증하지 않은 결과를 성공으로 보고하지 않는다.
